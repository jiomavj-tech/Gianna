# Gianna

App de celular (PWA) para registrar diariamente as observações do ciclo pelo Modelo Creighton, ver a ficha de selos, acompanhar gráficos e gerar PDF para a médica.

Os registros ficam guardados só no aparelho de quem usa. Este repositório contém apenas o código do app.

Endereço: https://jiomavj-tech.github.io/Gianna/
